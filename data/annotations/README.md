# Annotations Directory
# This directory stores JSON files with bounding box annotations
# Files are automatically created when you annotate images

# Format: annotation_XXXXX.json
# Each file contains:
# - image_index: Index of the image
# - has_plastic: Boolean indicating if plastic is present
# - boxes: Array of normalized bounding box coordinates
# - image_filename: Name of the image file
# - annotated_at: Timestamp of annotation
# - timestamp: Last update timestamp
